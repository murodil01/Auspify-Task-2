# Interactive Portfolio Website - Avery Morgan

An interactive, responsive, and modern personal portfolio website built with HTML5, CSS3, and JavaScript. Designed for a Product Designer & Developer persona, this project showcases creative projects, technical skills, and an accessible contact interface with clean UI/UX design.

## ✨ Features & Sections

- **Hero Section:** Introduction header featuring Avery Morgan (Product Designer & Developer) with a clear Call-to-Action (CTA).
- **About Section:** Background story, experience summary, and creative approach.
- **Projects Showcase:** Interactive card-based grid featuring past projects with hover animations.
- **Skills & Tools:** Visual breakdown of design and development expertise.
- **Interactive Contact Form:** Functional contact interface with JavaScript input handling/validation.
- **Smooth Navigation:** Seamless jump-links and responsive mobile menu navigation.
- **CSS Animations:** Smooth transition effects, button hover interactions, and dynamic layout behaviors.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and accessible markup
- **CSS3:** Custom styles, Flexbox, CSS Grid, Transitions, & Keyframe Animations
- **JavaScript (ES6):** Interactive UI logic, dynamic interactions, and form feedback
- **Deployment:** Git, GitHub, Vercel
